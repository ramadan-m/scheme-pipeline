Overall verdict

This is a solid, appropriately scoped take-home project: the calculation rules, API validation, and Mongo persistence are handled carefully. I found two concrete UI defects and two specific test weaknesses. I found no additional API contract or localhost security issue worth reporting. This review is based on tracing the source; I did not run tests, install packages, or run Git commands. No project source files were changed.
